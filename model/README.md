# :model

This module provides basic model classes like `Feed` and `Chapter`.
Classes are plain data objects with no Android dependencies and no business logic. The module is now **100% Kotlin** (`FeedOrder`, `FeedCounter`, `TranscriptType`, `DownloadError`, `DownloadStatus`, `TimerValue`, `TranscriptSegment`, `ProxyConfig`, `FeedFilter`, `DownloadResult`, `FeedItemFilter`, `Transcript`, `MediaType`, `SortOrder`, `VolumeAdaptionSetting`, `MediaMetadataRetrieverCompat`, `Chapter`, `FeedFunding`, `Feed`, `FeedItem`, `EmbeddedChapterImage`, `SubscriptionsFilter`, `FeedPreferences`, `DownloadRequest`, `Playable`, `RemoteMedia`, `FeedMedia`).
When converting a class from Java to Kotlin in this module, preserve the existing public Java API using `@JvmField`/`@JvmStatic`/`const val`, and avoid `data class` where the original Java relied on reference equality (i.e. no hand-written `equals`/`hashCode`).
`MediaMetadataRetrieverCompat.close()` is a documented no-unit-test exception: it is framework-pure (subclasses `android.media.MediaMetadataRetriever`, swallows `IOException` from `release()`) and cannot be exercised on the bare JVM; equivalence is verified by inspection plus `:app:assembleDebug` compiling for its downstream callers.
`DownloadRequest`/`Playable`/`RemoteMedia`/`FeedMedia` implement `android.os.Parcelable` (and, via `Playable`, `java.io.Serializable`) for real IPC marshalling into the download/playback services. Their `Parcel` round-trips are **lossy and asymmetric by design** — each type parcels only a subset of its fields, and applies transforms like null-auth-becomes-`""`-becomes-null or null-date-becomes-`Date(0)` on restore. Do not "fix" these divergences when touching these files; they are pinned by characterization tests (`DownloadRequestTest`, `RemoteMediaTest`, `FeedMediaTest`). Parcel/Bundle characterization tests for this cluster use Robolectric (`testImplementation libs.robolectric` in `model/build.gradle`) — a disclosed, one-time exception to this module's otherwise Robolectric-free unit test suite, needed because `android.os.Parcel`/`Parcelable`/`Bundle` are unimplemented stubs under bare-JVM tests. Do not add Robolectric to new tests outside this Parcel-marshalling cluster without the same justification.
`FeedMedia`/`RemoteMedia` carry `private const val serialVersionUID = 1L` (transitively `Serializable` via `Playable`) to defend against Kotlin's compiler computing a different implicit UID than javac would have.
