## Research outcome (2026-08-12)
- **Diagnosis confirmed, current.** `./gradlew --console=plain :app-wearos:compileFreeDebugKotlin` on `origin/develop` (`5ae7d560f`) fails with exactly one error: `EpisodeDetailActivity.kt:115:28 Argument type mismatch: actual type is 'String?', but 'String' was expected`. `FeedItem.title` is `var title: String? = null` (`FeedItem.kt:30`); pre-migration it was `private String title` + unannotated `getTitle()` (`git show b71cb7942^`).
- **It is genuinely one line, and this was verified, not argued.** In a throwaway detached worktree at `origin/develop` (created, probed, removed — the repo working tree was never modified), applying only `item.title ?: ""` at `:115` makes `compileFreeDebugKotlin`, `compilePlayDebugKotlin`, `ktlintCheck`, `lint`, `assemblePlayDebug` and `assembleFreeDebug` **all pass**. **No second latent compile error exists.**
- **The fix follows an in-module, same-commit, same-author precedent, not an invented idiom.** `MainListActivity.kt:99`, `FeedListActivity.kt:54` and `EpisodeListActivity.kt:64` all already use `?: ""` for the identical render, all written in `5fe70196e` alongside the failing line.
- **The fix is provably behaviour-neutral.** Every `FeedItem` reaching the watch UI comes from `WearSerializer.episodeFromJson`, which does `setTitle(optString(KEY_TITLE, ""))` (`WearSerializer.java:44`) — never null. Existing upstream test `WearSerializerTest.testEpisodesRoundTripNullTitle` (`:48-58`) already pins this. The `?: ""` branch is unreachable in production.
- **Two pre-research corrections.** (1) CI is **12 consecutive red runs back to 2026-07-24**, not 8 back to 2026-07-26 — the "8" was a `--limit 8` artifact. Last green: `30081326668` (2026-07-24T09:06:11Z); first red: `30081950299`, which is the push of the `:model` Chapter/FeedFunding/Feed/**FeedItem** conversion PR and whose log shows this exact error. Causation is established by CI record, not inference. (2) `:app-wearos` was last touched `cf30423ee` **2026-07-08**, not 2026-05-14 — three upstream commits landed in July. Still true that no portfolio milestone has touched it.
- **`:app-wearos` has no test source set at all** (`src/` contains only `main`), and there is **zero Compose UI test infrastructure repo-wide** (0 hits for `createComposeRule`; no Paparazzi, no `compose ui-test` in the version catalog). A characterization test for `:115` is not proportionately achievable — see Research Unknown 3, which the planner and red-team must ratify explicitly rather than leave as an omission.
- **`:app-wearos` is a leaf.** `settings.gradle:20` is the only reference to it anywhere; nothing depends on it. Blast radius is the watch APK alone. Note `AGENTS.md`'s module list omits both `:app-wearos` and `:net:sync:wear-interface` (Unknown 7 — flagged, not fixed).
